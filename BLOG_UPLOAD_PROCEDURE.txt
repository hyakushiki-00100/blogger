# ブログ記事アップロード手順書

このファイルは、雑学ブログの新しい記事を自動アップロードするための手順をまとめたものです。

## 1. 記事データの準備
`trivia_articles.json` に新しい記事を追加します。
各記事は以下のフィールドを持つ必要があります：
- `title`: 記事のタイトル
- `hook`: 導入文（リード文）
- `content`: 記事本体（HTML形式）
- `labels`: ラベルのリスト（最初のラベルがAmazon検索のキーワードになります）

## 2. イラスト画像の準備
記事のインデックス番号（JSON内での順番、0開始）に対応する名前で画像を保存します。
- 保存先: `images/` フォルダ
- ファイル名例: `207.png`, `208.png` など
- 対応形式: `.png`, `.jpg`, `.jpeg`, `.webp`

## 3. アップロードスクリプトの実行
ターミナルで以下のコマンドを実行します。
```powershell
python blogger_with_images.py
```

### スクリプトの動作：
1. **ブログIDの入力**: 実行時に Blogger のブログIDを求められます。
2. **画像アップロード**: `images/` 内の画像を自動で Catbox (外部ホスト) にアップロードし、URLを取得します。
3. **Amazonリンク生成**: 最初のラベルを使用して、アフィリエイトID `hyakushiki005-22` を含む検索リンクを自動生成します。
4. **HTML構成**: [画像] + [導入文] + [記事本体] + [Amazonリンク] の順で構成されます。
5. **予約投稿**: 毎日 **21:00** に投稿されるよう自動でスケジューリングされます（最後に予約されている日の翌日から順次設定されます）。

## 4. 注意事項
- **投稿制限**: スパム判定を避けるため、1回の実行でアップロードされるのは **最大3記事** までです。
- **連続実行**: さらに投稿したい場合は、前の実行が終わったあと、少し時間（数分〜数十分）を置いてから再度実行してください。
- **認証**: 初回実行時やトークン切れの際は、ブラウザが立ち上がり Google アカウントでの認証が求められます。
